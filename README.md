## 写作约定

1. 只记自己真正用到的参数组合和解法，附上踩坑场景。
2. 代码块标明语言（`bash` / `powershell` / `toml` / `yaml`），获得语法高亮。
3. 一个工具一个文件，超过 300 行考虑拆分。
