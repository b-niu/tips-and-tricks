# 常用快捷键速查（Windows / macOS）

只记高频、容易忘的组合，按使用场景分组。Mac 键位用 ⌘(Command) / ⌃(Control) / ⌥(Option) / ⇧(Shift) 表示。

## Windows

### 窗口与桌面管理

| 快捷键 | 作用 |
|--------|------|
| `Win + D` | 显示/恢复桌面 |
| `Win + E` | 打开文件资源管理器 |
| `Win + Tab` | 任务视图（多桌面/时间线） |
| `Win + Ctrl + ←/→` | 切换虚拟桌面 |
| `Win + Ctrl + D` | 新建虚拟桌面 |
| `Win + Ctrl + F4` | 关闭当前虚拟桌面 |
| `Alt + Tab` | 切换窗口 |
| `Alt + F4` | 关闭当前窗口 |
| `Win + ←/→` | 窗口贴边分屏（左半/右半） |
| `Win + ↑/↓` | 窗口最大化 / 还原、最小化 |
| `Win + M` | 最小化所有窗口 |
| `Win + ,` | 临时窥视桌面（按住显示，松开恢复） |

### 系统与搜索

| 快捷键 | 作用 |
|--------|------|
| `Win + S` | 打开搜索 |
| `Win + I` | 打开设置 |
| `Win + L` | 锁屏 |
| `Win + X` | 打开快捷菜单（电源/设备管理器/终端等） |
| `Ctrl + Shift + Esc` | 直接打开任务管理器 |
| `Win + V` | 剪贴板历史（首次使用需开启） |
| `Win + .` | 表情符号/特殊符号面板 |
| `Win + P` | 投影/多屏切换 |
| `Win + Shift + S` | 截图（区域截图，含延时） |
| `PrtScn` / `Alt + PrtScn` | 全屏截图 / 当前窗口截图到剪贴板 |

### 文本编辑通用

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + ←/→` | 按词跳转光标 |
| `Ctrl + Shift + ←/→` | 按词选中 |
| `Home / End` | 行首 / 行尾 |
| `Ctrl + Home / End` | 文档开头 / 结尾 |
| `Ctrl + Z / Y` | 撤销 / 重做 |
| `Ctrl + F / H` | 查找 / 替换 |
| `Ctrl + Shift + V` | 无格式粘贴（部分编辑器支持） |

### PowerToys 增强快捷键

实际开启的功能与键位（PowerToys v0.101.2362，改键后需同步更新此表）。

| 功能 | 快捷键 | 作用 |
|------|--------|------|
| 裁剪并创建缩略图（Crop and Lock） | `Win + Ctrl + Shift + T` | 截取窗口区域做成置顶缩略图 |
| 将应用窗口裁剪为裁剪窗口 | `Win + Ctrl + Shift + R` | Crop and Lock 子模式：裁剪后独立成窗 |
| 将应用裁剪到屏幕截图窗口中 | `Win + Ctrl + Shift + S` | Crop and Lock 子模式：裁剪到截图窗口 |
| 激活快捷键（Always On Top） | `Win + Ctrl + T` | 当前窗口置顶/取消置顶 |
| 增加不透明度 | `Win + Ctrl + =` | 置顶窗口透明度调节 |
| 降低透明度 | `Win + Ctrl + -` | 置顶窗口透明度调节 |
| 预览文件（Peek） | `Ctrl + Space` | 不打开应用快速预览文件 |
| 打开"运行"（PowerToys Run） | `Alt + Space` | 启动器/快速搜索，类似 macOS Spotlight |

> 注：`Ctrl + Space`（Peek）与部分输入法的中英文切换冲突；`Alt + Space` 与系统窗口控制菜单冲突（PowerToys 会接管），若异常可在 PowerToys 设置中改键。

## macOS

### 窗口与桌面管理

| 快捷键 | 作用 |
|--------|------|
| `⌘ + Tab` | 切换应用（按住 `⌥` 再松开 `⌘` 可回到原应用） |
| `⌘ + ~` | 同一应用多窗口间切换 |
| `⌘ + W` | 关闭当前标签/窗口 |
| `⌘ + Q` | 退出整个应用 |
| `⌘ + M` | 最小化窗口 |
| `⌘ + H` | 隐藏应用 |
| `⌘ + ,` | 打开当前应用偏好设置 |
| `F3` / `⌃ + ↑` | 调度中心（Mission Control） |
| `⌃ + ←/→` | 切换空间（虚拟桌面） |
| `⌘ + 空格` | 聚焦搜索（Spotlight） |

### 系统与截图

| 快捷键 | 作用 |
|--------|------|
| `⌘ + Space` | Spotlight 搜索（可当计算器/启动器用） |
| `⌃ + ⌘ + Q` | 锁屏 |
| `⌘ + ⇧ + 3` | 全屏截图 |
| `⌘ + ⇧ + 4` | 区域截图（再加空格可截取窗口） |
| `⌘ + ⇧ + 5` | 截图/录屏控制台（含延时、存储位置设置） |
| `⌃ + ⌘ + Space` | 表情符号面板 |

### 文本编辑通用

| 快捷键 | 作用 |
|--------|------|
| `⌥ + ←/→` | 按词跳转光标 |
| `⌘ + ←/→` | 行首 / 行尾 |
| `⌘ + ↑/↓` | 文档开头 / 结尾 |
| `⌥ + ⇧ + ←/→` | 按词选中 |
| `⌘ + ⇧ + ←/→` | 选中到行首 / 行尾 |
| `⌘ + Z / ⇧ + Z` | 撤销 / 重做 |
| `⌘ + F / ⌥ + ⌘ + F` | 查找 / 替换 |

## 踩坑记录

- PowerToys 快捷键（如 `Win + Ctrl + Shift + T`）常与微信/QQ 截图等软件冲突，改键后要同步更新此表。
- Windows `Ctrl + Shift + V` 无格式粘贴并非全局生效，微信、VS Code、浏览器文本框支持情况不一；Word 用 `Ctrl + Alt + V`。
- macOS 截图默认存到桌面，`⌘ + ⇧ + 5` 里可改为存到剪贴板（加 `⌃` 也行：`⌃ + ⌘ + ⇧ + 4` 直接入剪贴板）。
- `⌘ + Tab` 是应用级切换，窗口级要用 `⌘ + ~`，这是 Windows 用户最容易混淆的点。
