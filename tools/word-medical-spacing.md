# 医学论文空格清洗（Word / WPS 通配符）

## 核心原则

- 只删除**中文与西文之间**的冗余空格，保留科学计量单位及英文术语内部的规范空格。
- 数字与计量单位之间保留一个半角空格（SI 规范），但最终以目标期刊的 Author Guidelines 为准（如 JMIR 用 `95%`，SI 严格写法为 `95 %`）。

## 删除与保留速查

| 场景 | 原始写法 | 推荐写法 |
|------|---------|---------|
| 中文与英文 / 数字 | 采用 CT 检查、纳入 102 例患者 | 采用CT检查、纳入102例患者 |
| 中文与模型名 / 希腊字母 / 统计量 | 使用 nnU-Net 模型、参数 α、P 值 | 使用nnU-Net模型、参数α、P值 |
| 数字与单位 | `5 mm`、`100 mm³`、`30 min`、`50 mg`、`10 mSv`、`−800 HU`、`120 mmHg`、`37 °C` | 原样保留空格 |
| 数学与专业表达式 | `P < 0.05`、`deep learning`、`3D Slicer`、`¹⁸F-FDG` | 原样保留空格 |
| 角度 / 百分号 | `30 °`、`95 %` | `30°`、`95%`（医学期刊惯例；温度 `37 °C` 保留空格） |

## 两步替换

勾选「使用通配符」，依次执行「全部替换」。字符集已扩大到希腊字母、常见符号及上下标，但不含数学运算符；仅处理普通半角空格。

第 1 步：删除中文后面的空格

```text
查找：([㐀-䶿一-鿿]) @([a-zA-Z0-9Α-Ωα-ωµ%‰°℃℉²³⁰¹⁴-⁹₀-₉])
替换：\1\2
```

第 2 步：删除中文前面的空格

```text
查找：([a-zA-Z0-9Α-Ωα-ωµ%‰°℃℉²³⁰¹⁴-⁹₀-₉]) @([㐀-䶿一-鿿])
替换：\1\2
```

` @` = 一个普通半角空格 + `@`，用于匹配一个或多个连续空格。

## 为什么不会破坏数字与单位

两个表达式都要求空格**一侧必须是汉字**，所以 `1.0 mm`、`−600 HU` 这类数字与单位间的空格不会被匹配，无需维护单位白名单，也不用枚举 `mm`、`mg`、`HU`、`mSv` 等。

效果示例：`纳入 102 例患者，采用 nnU-Net 模型对 CT 影像进行分割。CT 扫描层厚为 1.0 mm` → `纳入102例患者，采用nnU-Net模型对CT影像进行分割。CT扫描层厚为1.0 mm`。

## 可选：标点清理（按需单独执行）

| 作用 | 查找 | 替换为 |
|------|------|--------|
| 删除中文标点前的空格 | ` @([，。；：！？、）】》])` | `\1` |
| 删除中文左括号后的空格 | `([（【《]) @` | `\1` |
| 删除百分号前的空格 | `([0-9]) @%` | `\1%` |
| 多个连续空格合并为一个 | ` {2,}` | 一个半角空格 |

注：右括号规则已包含在「中文标点前」规则中，无需重复；最后一项可能影响手动对齐文本，谨慎使用。

## 不建议自动处理

- 特殊语义符号：`+`、`−`、`±`、`×`、`=`、`<`、`>`、`≤`、`≥`、`/`、`–`、`-`、`()`，例如 `12.5 ± 2.3 mm`、`P < 0.05`、`10 mg/kg`、`OR (95% CI)`。
- 不要用一条通用规则在所有数字与字母间插入空格，否则会破坏 `3D`、`T2`、`Ki-67`、`18F`、`COVID-19`。
- 已有的错误写法如 `10mm`、`50mg` 不会被自动修正。

## 建议与注意

- 日常只用两步医学增强版，必要时再执行标点清洗。
- 尚未在 Word / WPS 客户端验证扩展 Unicode 区间的兼容性，也不能保证捕获组替换完整保留加粗、斜体、上下标等格式；首次使用先在副本上测试。
